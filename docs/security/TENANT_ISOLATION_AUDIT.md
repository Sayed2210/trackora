Date: 2026-08-04
Severity: P0 Security / Tenant Isolation Breach

No customer records or values are included in this report.

## Intentionally global entities

- `Plan` and plan feature definitions: platform-managed product catalog.
- `FeatureFlag`: global flag definition; tenant overrides remain tenant-owned.
- `Zone`: shared MENA delivery reference hierarchy in the current schema. Tenant-owned zone overrides do not exist.
- `WhatsAppTemplate`: shared messaging template catalog in the current schema.
- `DemoRequest`: public pre-tenant lead intake.
- `BlacklistedPhone`: currently a platform-wide fraud control. A future policy decision is required if blacklists must become tenant-specific.

Platform tenant, subscription, billing, analytics, support, and platform audit endpoints remain intentionally cross-tenant and are protected by `PlatformOnlyGuard` plus platform permissions. Direct platform identities cannot enter operational tenant endpoints without an active validated impersonation session.
